# Security Policy

## Supported Versions

We support the latest released version while we're in development, according to the github release page. We do not support older releases.

## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

Tell them where to go:
 - Email contact@tomjn.com

how often they can expect to get an update on a reported vulnerability:
 - As the reporter you're expected to be a participant in fixing the vulnerability and included in comms directly.

What to expect if the vulnerability is accepted or
declined, etc:
 - Hopefully we can figure out a fix as quickly as possible and ship a release, but other than that goodwill is the prize, there's no bug bounty program here.
