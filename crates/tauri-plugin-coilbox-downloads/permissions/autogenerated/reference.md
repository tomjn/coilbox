## Default Permission

Allows the downloads plugin's commands (version, rapid browsing, springfiles/BAR listing, downloads).

#### This default permission set includes the following:

- `allow-dl-version`
- `allow-dl-cancel`
- `allow-dl-repos`
- `allow-dl-versions`
- `allow-dl-download`
- `allow-dl-springfiles-list`
- `allow-dl-springfiles-engines`
- `allow-dl-bar-maps`
- `allow-dl-hakora-maps`
- `allow-dl-download-map`
- `allow-dl-download-file`
- `allow-dl-recoil-engines`
- `allow-dl-github-latest-release`
- `allow-dl-github-release-archives`
- `allow-dl-download-engine-recoil`
- `allow-dl-download-engine-spring`
- `allow-dl-installed-content`
- `allow-dl-set-engine-dirs`
- `allow-dl-path-writable`
- `allow-dl-fetch-text`
