## Default Permission

Allows the unit builder's project storage, thumbnail, reveal and test-game commands.

#### This default permission set includes the following:

- `allow-lego-list`
- `allow-lego-save`
- `allow-lego-delete`
- `allow-lego-thumb-save`
- `allow-lego-open-path`
- `allow-lego-packs`
- `allow-lego-read-s3o`
- `allow-lego-import-s3o`
- `allow-lego-texture-import`
- `allow-lego-texture-prune`
- `allow-lego-export`
- `allow-lego-export-glb`
- `allow-lego-export-obj`
- `allow-lego-scratch-game`
