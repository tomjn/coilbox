## Default Permission

Allows the unit builder's project storage, thumbnail and reveal commands.

#### This default permission set includes the following:

- `allow-lego-list`
- `allow-lego-save`
- `allow-lego-delete`
- `allow-lego-thumb-save`
- `allow-lego-open-path`
