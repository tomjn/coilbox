## Default Permission

Allows the roguelite-run plugin's active-run and meta-progression storage commands.

#### This default permission set includes the following:

- `allow-runlite-state-load`
- `allow-runlite-state-save`
- `allow-runlite-meta-load`
- `allow-runlite-meta-save`
