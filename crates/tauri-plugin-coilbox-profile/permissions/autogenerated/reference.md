## Default Permission

Allows reading the bundler-supplied distribution profile.

#### This default permission set includes the following:

- `allow-profile-load`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`coilbox-profile:allow-profile-load`

</td>
<td>

Enables the profile_load command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`coilbox-profile:deny-profile-load`

</td>
<td>

</td>
</tr>
</table>
