## Default Permission

Allows the conquest plugin's galaxy storage, import/export and run-state commands.

#### This default permission set includes the following:

- `allow-conquest-list`
- `allow-conquest-save`
- `allow-conquest-delete`
- `allow-conquest-export`
- `allow-conquest-import`
- `allow-conquest-state-load`
- `allow-conquest-state-save`
