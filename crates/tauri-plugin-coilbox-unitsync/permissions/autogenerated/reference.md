## Default Permission

Allows the unitsync plugin's content-scan, minimap, heightmap, thumbnail, game-info, engine-config, archive browse/extract and Lua-console commands.

#### This default permission set includes the following:

- `allow-unitsync-scan`
- `allow-unitsync-minimap`
- `allow-unitsync-heightmap`
- `allow-unitsync-metalmap`
- `allow-unitsync-thumbnails`
- `allow-unitsync-map-meta`
- `allow-unitsync-game-info`
- `allow-unitsync-unit-buildpics`
- `allow-unitsync-faction-logos`
- `allow-unitsync-unit-dataset`
- `allow-unitsync-unit-model`
- `allow-unitsync-map-info`
- `allow-unitsync-map-skybox`
- `allow-unitsync-skirmish-ais`
- `allow-unitsync-engine-config`
- `allow-unitsync-engine-config-set`
- `allow-unitsync-archive-tree`
- `allow-unitsync-archive-file`
- `allow-unitsync-game-headers`
- `allow-unitsync-lua-exec`
- `allow-unitsync-lua-repl-exec`
- `allow-unitsync-archive-extract`
- `allow-unitsync-cancel`
