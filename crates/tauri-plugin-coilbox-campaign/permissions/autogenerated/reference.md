## Default Permission

Allows the campaign plugin's storage, image import/read and progress commands.

#### This default permission set includes the following:

- `allow-campaign-list`
- `allow-campaign-save`
- `allow-campaign-delete`
- `allow-campaign-image-import`
- `allow-campaign-image-import-data`
- `allow-campaign-image-read`
- `allow-campaign-image-delete`
- `allow-campaign-export`
- `allow-campaign-import`
- `allow-campaign-progress-load`
- `allow-campaign-progress-save`
