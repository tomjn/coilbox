## Default Permission

Allows the scenario plugin's storage and dialogue-media commands.

#### This default permission set includes the following:

- `allow-scenario-list`
- `allow-scenario-save`
- `allow-scenario-delete`
- `allow-scenario-media-import`
- `allow-scenario-media-delete`
