# Reference

Lists and formats that are coilbox's own, to look things up in. The guides link here where they need to.

Formats and protocols that another project owns, such as the engine's model formats and the lobby protocols, are documented by that project and not here.

- [Routes and navigation ids](routes.md). Every screen's `#/` link, and every id a distribution profile can hide.
- [Replay data sources](replay-data-sources.md). Which source each figure on a replay page comes from, what each one costs to read, and why two figures can disagree.
- [Parts pack format](lego-parts-pack.md). The library of textured parts the unit builder assembles units from.
- [Replay track format](replay-track-format.md). The file that records where everything was during a replay, so the replay can be played backwards.
