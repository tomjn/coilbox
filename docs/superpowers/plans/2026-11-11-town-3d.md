# 3D towns implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Towns on a terrain map are drawn as blocks of 3D placeholder buildings on a street grid, on ground levelled for them, and the painted towns and their fields are removed.

**Architecture:** A new folder `src/conquest/galaxy3d/towns3d/` holds pure levelling, a building inventory, a pure layout and a layer that draws one merged mesh per town with the landmark material and shadow. `GalaxyView` plans roads and towns on the raw heights, levels the heights, then builds everything else on the levelled surface.

**Tech stack:** TypeScript, three.js, vitest (node environment), agent-browser for harness shots, Tauri MCP for on-screen checks.

**Spec:** `docs/superpowers/specs/2026-11-11-town-3d-design.md`. Read it before any task.

**Port source:** `docs/reports/town-3d/` (gitignored, throwaway). `placeholders.ts` holds the layout and the cuboid list, `city.ts` the levelling, the merge per town, the street sheet and the shadow bake. Copy from it, never import. If the folder is gone, the formulas in this plan are enough.

## Global constraints

- A standard lot is 0.25 world units. A sealed outpost's lot is 0.75. Sealed planets are those whose `planetOf(id).settlement.style` is `"sealed"`: red, moon, volcanic, acid. A map with no planet is temperate.
- Levelling never moves a height across sea level. Sea is a grid value at or below `0.5 / 255`.
- Levelling returns new grids. It never writes to the grids it is given, because generated pixels are shared between views.
- Town palettes take nothing from `Planet.settlement` colours.
- The terrain shader and the terrain picture are not changed. `renderer.shadowMap` stays off.
- Town meshes, street sheets and decals set `raycast = () => {}`.
- Every geometry, material, texture and render target goes into `disposables`.
- No violet mist is drawn on a 3D town.
- Comments follow the repo's plain English style. No em dashes.
- Three PRs, one after another, never stacked. PR 1 is tasks 1 to 4, PR 2 is tasks 5 to 11, PR 3 is task 12. Start each PR's branch from `origin/main` after the one before has merged. PR 1 uses the existing branch `feat/town-3d`, which already holds the spec and this plan.
- Before any PR: `bun run check` passes, the user has had the shots and a chance to run `bun tauri dev`. PRs go through the `file-pr` skill.
- Never ask through `AskUserQuestion`. Shots go in `docs/reports/town-3d/shots/` and are shown to the user in the reply.
- Measure frame timing only when the 1 minute load average is below 6, as `scripts/map-frame-timing/README.md` says.

## Review focus

1. A town with almost no buildable ground, such as a sliver of coast: the layout returns one building or none, nothing throws, and the layer skips a town with no placements. Tests in tasks 7 and 9.
2. Two towns whose skirts overlap: the result is the same in either order and has no step between them. Test in task 1.
3. A hand-made map that asks for towns and has no extension, no relief, no planet and a picture given as a URL: heights alone are levelled, the palette is temperate, nothing throws. Tests in tasks 3 and 9.
4. Performance mode, or a hand-made map without towns: no planning surface work is kept, and the heights handed on are the very same object. Test in task 3.
5. Reopening a map many times: the shared generated grids are never changed, so a second open levels from the same land, and every render target is disposed. Tests in tasks 1 and 9.

export const SEA_HEIGHT = 0.5 / 255;
/** Flat inside this share of the town's edge. */
export const LEVEL_CORE = 0.95;
/** Back to the land's own height at this share of the town's edge. */
export const LEVEL_SKIRT = 1.7;

export interface LevelFrame { worldWidth: number; worldDepth: number }
export interface GroundGrids {
  heights: HeightGrid;
  /** The wider grids, with `margin` pixels past the map each side. */
  extension?: { heights: HeightGrid; relief?: HeightGrid; margin: number };

`levelGround` returns `grids` itself when `towns` is empty. Otherwise it returns a copy of `grids` whose `heights`, `extension.heights` and `extension.relief` are new `HeightGrid`s. Every other field of `extension` is carried over by reference.

- [ ] **Step 3: Implement `level.ts`**

A grid's pixel `(i, j)` with margin `m` stands at world `x = ((i - m) / (width - 2m - 1) - 0.5) * worldWidth`, and the same in z. This matches `sampleHeightGrid` on the map's grid and `createMarginSurface` on the wider ones.

For a pixel at share `t = distance / townEdge(town, angle)` of a town's edge, the town's pull is `w = 1 - smoothstep(LEVEL_CORE, LEVEL_SKIRT, t)`. Levels come from the map's `heights` alone and are used for all three grids. With `W` the sum of the pulls on a pixel and `P` the sum of each pull times its town's level:

```ts
out = raw <= SEA_HEIGHT ? raw : raw + (P - raw * W) / Math.max(1, W);
```

Visit only the pixels within `radius * 1.27 * LEVEL_SKIRT` of each town. Accumulate `W` and `P` in two scratch arrays the size of the grid, then write the output in one pass, so the order of the towns cannot matter.

- [ ] **Step 3: Implement, porting `layoutCity` from the spike**

The grid, in the town's own frame (u along `town.axis`, v across):

- Block `i` from 0 starts at `avenue / 2 + i * (block + street) + floor(i / avenueEvery) * (avenue - street)`, and its mirror at minus that, less the block. Blocks run out to `radius * 1.3`.
- The random source is `seeded(Math.floor(town.seed * 1e9))`.
- Each lot is judged once, at its centre, before any model is tried. With `t` the centre's distance as a share of `townEdge`, the lot is empty when `t > 1`, when it lies within `(boulevard + lot) / 2` of a street's ray from the centre, when `buildable < BUILD_FIT`, when `riverEdge < RIVER_BANK`, or when `rand() > 1 - (1 - edgeDensity) * t * t`.
- Otherwise its wanted height is `tallest * stature * (0.06 + 0.94 * (1 - t) ** 1.8) * (0.45 + 0.9 * rand())`, with `tallest` the tallest model given and `stature = Math.min(1, town.radius / CAPITAL_RADIUS) ** 0.7`.
- A lot takes the model nearest its wanted height whose lots, either way round, are all free and not empty. A model on more than one lot counts as 0.02 nearer.
- The fallback is the lowest single-lot model at the town's own position, when nothing was placed and the centre passes the buildable and river tests.

`riverEdgeReader` reads the field's nearest texel at `u * (width - 2 * margin) / width + margin / width`, and the same down, for a point `u, v` across the sheet. The byte over 255, times `RIVER_FIELD_INSIDE + RIVER_FIELD_OUTSIDE`, less `RIVER_FIELD_INSIDE`, is the distance. This is what `townShader.ts` line 948 reads.

How a town is built, ported from the spike's `city.ts`:

- Settlement style is `planetOf(planet ?? "temperate").settlement.style`. Each model's geometry is built once for the map with `buildModel` at its `footprint`.
- The group stands at the town's position and its ground height `y0`. Each placement copies its model's geometry to `at(x - town.x, top - y0, z - town.z, placement.turn)`, where `top` is the highest ground under its four corners. Its colours are multiplied by `1 + (rand() - 0.5) * 0.14`, the kit's own drift between parts.
- Where the lowest corner is more than 0.001 below `top`, a plain foundation box in `palette.building` fills the gap, so no side shows daylight on a slope.
- All copies and foundations merge into one geometry and one `landmarkMaterial()` mesh. A town with no placements adds nothing and is not in `nodes`.
- The street sheet is a grid mesh at a step of 0.08 over the town's bounding square, draped on the ground with a lift of 0.008. Its colour is `palette.street` at an opacity of 0.9, fading to nothing from 0.9 to 1.08 of the town's edge and absent over sea. It is a `MeshBasicMaterial` with `transparent`, `depthWrite: false`, `polygonOffset` at factor -1 and units -2, and `renderOrder` -2.45, between the province fills and the decal. A hidden town's sheet is drawn at 0.7 of its colour.
- `shadowSide(radius)` is the smallest power of two at or above `2048 * radius / CAPITAL_RADIUS`, and never more than 2048.
- The decal is `groundDecal(surface, site, town.radius * 1.38, null, shadowReach, { contact: false })`. The 1.38 puts the decal's ring, drawn at 0.92 of its reach, at the town's furthest edge, 1.27 radii. `shadowReach` is that reach plus the tallest building's height times `hypot(sun.x, sun.z) / sun.y`, the length of its shadow on level ground.
- `tops` holds the merged geometry's highest world y.
- `shadowBytes` is 8 bytes a texel, summed over the towns: 4 for the colour target and 4 for the depth.
